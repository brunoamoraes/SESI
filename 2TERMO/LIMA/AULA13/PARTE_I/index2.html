Comandos Git

git init - Esse comando cria o repositório Git Local

git status - checar status do repositório

git add - irá adicionar esse arquivo em processo de envio

git commit - Representar a confirmação do processo ou seja, enviar

git log - mostrar o log ou registro das evoluções feitas no repositório

git branch - Branches - representa uma linha de desenvolvimento

Criando repositório

Preciso do meu repositório criado no github para dar inicio as configurações de publicação do projeto

Por que não criar o README.md?

Por que nosso projeto já possui um histórico. Manter o remoto vazio simplifica a conexão e evita históricos diferentes.

git remote add origin - adicionar o repositório remoto

git remote -v - visualizar conexão remote git

O que é Origin?

É um nome convencional dado ao repositório remoto

git push - envia a branch main , usa o remoto origin e configura o acompanhamento entre branch local e remote

git push -u origin main

git push - Serão ações futuras

git pull - Quando possuimos alterações que ainda não estão no seu computador

Fluxo completo diariamente

git pull - inicio dos trabalhos

git status - Edição do projeto

git add . - Edição do projeto

git commit -m - "Edição do projeto"

git push - Edição do projeto
